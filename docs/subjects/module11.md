## Course:Advanced Remote Sensing
### Content
- Space and Earth observation (EO) applications, Copernicus missions
- Spatial concepts in image analysis
- Hyperspectral remote sensing – principles
- Radio detection and ranging (RaDAR) – techniques and applications
- Hyperspatial remote sensing (RPAS) – techniques and applications
- Light detection and ranging (LiDAR) – techniques and applications
- Radiometric correction
- Image segmentation
- Image convolution
- Filters / CNN
- Knowledge representation
- Knowledge-based classification
- Advanced statistical classifiers (SVM, Random Forest)
- Class modelling
- Quality assessment and validation
